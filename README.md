# Hello World 👋 I’m Joey (joeymsu)

Computer Science + Computational & Applied Mathematics student at Michigan State University. I like building software that is reproducible, testable, and easy to run, especially for data-heavy or research-style workflows.

What I work with most:
- Python for data work, ML experimentation, and automation (NumPy, Pandas, Jupyter, Matplotlib, Seaborn)
- ML frameworks for modeling and prototyping (PyTorch, TensorFlow)
- Web fundamentals and modern stacks (HTML/CSS/JS, React, Node.js, Express, REST APIs)
- Systems + tooling for real deployments and scale (Linux, Bash, Git/GitHub, CI, Docker, Singularity, SLURM)
